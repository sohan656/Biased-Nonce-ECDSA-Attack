The attack in one relation

s = (z + r·d) / k (mod n)   // ECDSA signing
⇒ k = (z/s) + (r/s)·d (mod n)   // isolate the nonce

biased k (e.g. top l bits = 0) ⇒   a·d + b (mod n) is small  // a=r/s, b=z/s → Hidden Number Problem
LLL finds the short vector ⇒ read off d ⇒ verify Q = d·G

Defense (demonstrated)

RFC 6979   Deterministic nonces remove the bias the attack needs. The same lattice pipeline that breaks biased ECDSA fails against RFC-6979 signatures (key not recovered, Q not matched). Run python3 experiments/mitigation_demo.py.
